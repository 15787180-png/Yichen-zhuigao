# 追高计划

给家长用的孩子身高 / 运动 / 饮食 / 睡眠记录网页。手机优先，纯前端，双击 `index.html` 就能用，不联网也能跑。

> 因为孩子正在做身高管理，需要一个每天能点得动、又能看清趋势的东西，就自己写了这个。代码全部开源，你可以直接改。

## 它记什么

| 模块 | 内容 |
|---|---|
| 首页 | 当前身高、比上次涨了多少、本月运动天数、本月跳绳总数、连续运动天数、今日待办 |
| 动 | 一套跳绳为主的运动方案：跳绳200 → 弹簧跳50 → 跳绳200 → 伸展跳50 → 跳绳200 → 开合跳50 → 跳绳200 → 高抬腿50 → 跳绳200 → 勾脚跳50 → 拉伸2分钟 |
| 吃 | 每日菜单轮换、学校午餐建议、过敏原规避 |
| 成长 | 身高曲线、身高记录（可补记旧日期、可改历史记录）、周报 |
| 我的 | 孩子档案、注射日程、病历与报告归档、数据导出导入 |

## 怎么跑

```
直接双击 index.html
```

或者起个静态服务（手机上访问更方便）：

```
python -m http.server 5311
```

然后手机连同一个 WiFi，浏览器打开 `http://你的电脑IP:5311/`。

## 数据存在哪

全部在浏览器本地（`localStorage`，键名 `zhui_v1`），不上传任何服务器。

所以要注意：

- 换浏览器、换手机、清缓存 → 数据不会自动跟过去
- 要搬数据：**我的 → 导出数据**，在新设备上 **导入数据**
- 写入前会自动留一份 `zhui_v1_bak`，每天第一份存快照 `zhui_v1_snap_YYYYMMDD`（留最近 10 天）

## 云端功能（可选，默认关闭）

代码里的 `js/cloud.js` 预留了三个能力：登录、多设备备份、病历照片自动识别。默认是空的，界面上也不会显示相关入口。

想打开，把 `CFG` 里三项换成你自己的：

```js
const CFG = {
  endpoint: 'https://你的云服务地址',
  oauthRelayBaseUrl: 'https://www.workbuddy.cn/v2/as/genie-baas/oauth',
  publishableKey: 'wbpk_你自己的key'
};
```

⚠️ 这些功能会把病历照片发给云端大模型做识别，**按调用量收费，扣的是 key 所属账号的钱**。所以这里的 key 我留空了，你自己填自己的。

## 目录

```
index.html            入口
css/app.css           全部样式
js/data.js            档案默认值、运动方案、饮食知识
js/data-menu.js       菜单库
js/data-sea.js        海产替代与过敏原识别
js/store.js           状态、存取、统计、备份
js/ui.js              弹层、提示、图标
js/sheets.js          各类录入表单
js/cloud.js           云端能力（默认关闭）
js/views-*.js         各个页面
js/app.js             路由与启动
sw.js                 Service Worker（离线缓存）
```
